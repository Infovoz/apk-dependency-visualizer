# Визуализатор графа зависимостей пакетов Alpine Linux (apk)

## 1. Общее описание
Консольный инструмент командной строки для исследования, послойного анализа и визуализации графа зависимостей пакетов Alpine Linux (`apk`) без использования сторонних пакетных менеджеров и специализированных библиотек. Метаданные пакетов читаются и распаковываются напрямую из архива `APKINDEX.tar.gz` по HTTP стандартными средствами Python (`urllib.request`, `tarfile`, `io`).

Программа строит полный граф зависимостей с помощью рекурсивного алгоритма поиска в ширину (BFS), строго контролирует максимальную глубину анализа, обнаруживает циклические зависимости, вычисляет топологический порядок загрузки (установки) пакетов и генерирует представление в виде ASCII-дерева и диаграммы PlantUML.

Реализованы в полном объёме все этапы практической работы:
- **Этап 1.** Минимальный прототип с разбором параметров командной строки и валидацией.
- **Этап 2.** Сбор и извлечение прямых зависимостей из архива `APKINDEX.tar.gz`.
- **Этап 3.** Построение графа рекурсивным BFS, отсечение по глубине, обработка циклов и поддержка тестового репозитория.
- **Этап 4.** Определение порядка загрузки (установки) зависимостей.
- **Этап 5.** Генерация текстового описания графа PlantUML и ASCII-дерева, сравнение со штатным инструментом `apk dot`.

## 2. Описание функций и настроек

### Параметры командной строки
- `--package <ИМЯ>` — имя анализируемого пакета (обязательный параметр).
- `--repo <URL/ПУТЬ>` — URL-адрес архива `APKINDEX.tar.gz` или путь к файлу тестового репозитория (обязательный параметр).
- `--test-mode` — флаг включения режима работы с синтетическим тестовым репозиторием.
- `--ascii-tree` — флаг вывода графа зависимостей в формате дерева псевдографики ASCII.
- `--max-depth <ЧИСЛО>` — максимальная глубина послойного анализа зависимостей (целое положительное число).

### Режим тестового репозитория
В тестовом режиме (`--test-mode`) граф зависимостей считывается из локального текстового файла.
